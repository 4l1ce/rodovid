# rodovid-agent — AI-асистент для пошуку предків в українських архівах

Плагін для Claude, який перетворює генеалогічне дослідження на керований
процес: від «де це взагалі може бути» до запису в дереві з джерелом і
рівнем достовірності. Зібраний із реальної роботи над родоводом Борзни і
Вибель (Чернігівщина): метрики 1880–1890-х, сповідні розписи 1763–1846,
ревізії 1850–1858, Румянцевський опис 1766–1767.

## Принципи

1. **Кожне твердження — до зображення.** Архів, ф.-оп.-спр., знімок, посилання.
2. **Індекс — це зачіпка, скан — це доказ.**
3. **Незалежна перевірка.** Ключові прочитання перечитує агент, який їх не робив.
4. **Рівні достовірності:** підтверджено / ймовірно / гіпотеза / не знайдено.
5. **Відсутність ≠ доказ відсутності,** доки не перевірено повноту джерела.
6. **Людина затверджує** кожну зміну в дереві й кожен запит до архіву.

## Скрипти (Python 3 + openpyxl)

```
search_index.py   DIR --surname Третьяк [--mode exact|prefix|fuzzy] [--given] [--patronymic] [--role]
families.py       DIR --surname Бугай --mode prefix
coverage.py       DIR --kind birth
check_transcription.py "Борзнянський повіт 1890 рік метрики.xlsx"
index_writer.py   init|add FILE --sheet birth --from rows.json
ledger.py         init|add|set|summary FILE
```

Приклад: `families.py` по Третяках Борзни 1887–1892 за секунду збирає
20 родин із дітьми, смертями й хрещеними і сам підсвічує, що «Григорий» і
«Георгий Афанасьев Бугай» мають одну дружину — тобто, ймовірно, це одна
людина, записана двома формами імені.

## Встановлення

У Claude Code:

```
/plugin marketplace add 4l1ce/rodovid
/plugin install rodovid-agent@rodovid
```

Або як файл (Claude Desktop, claude.ai):

1. Відкрийте [останній реліз](https://github.com/4l1ce/rodovid/releases/latest)
   і завантажте `rodovid-agent-<версія>.plugin` (або `.zip` — це той самий
   архів).
2. Завантажте файл у Claude як плагін і натисніть «Install».

Зелена кнопка GitHub «Code → Download ZIP» для цього не підходить: вона
кладе файли в додаткову теку `rodovid-main/`. Беріть файл із релізу.

Для роботи з FamilySearch потрібен ваш акаунт і браузер (Claude in Chrome
або вбудований браузер Claude). Паролі агент не вводить.

## Обмеження

- Читання рукописів AI помиляється — тому верифікатор і рівні достовірності.
- Багато фондів онлайн немає; плагін допомагає швидко це встановити і
  скласти точний запит до архіву.
- Живих людей не досліджуємо й не публікуємо.
- Детальні довідки про фонди (номери, каталоги, хмара) поки є лише для
  Чернігівщини (ДАЧО). Для інших областей агент сам визначає потрібний
  обласний архів і шукає його фонди й описи.

## Дані та конфіденційність

Плагін не має власного сервера і нічого не надсилає автору.

**Які персональні дані він читає і зберігає.** Імена, дати, місця і
родинні зв'язки людей з архівних документів (майже всі давно померлі); для
чернеток запитів до архіву — ваші ім'я та контакти. Усе це зберігається
лише у файлах на вашому комп'ютері чи у вашому проєкті: xlsx-індекси й
реєстр доказів, нотатки справи в markdown, чернетки запитів. Живих людей
не досліджуємо і не додаємо до спільних дерев.

**Якими зовнішніми сервісами користується** — завжди через ваш власний
браузер (Claude in Chrome або вбудований браузер Claude) і звичайні
сторінки сайтів. Агент ніколи не читає cookie чи токени, не викликає
внутрішні API і не вводить паролі:

| Сервіс | Що передається | Коли |
|---|---|---|
| FamilySearch (familysearch.org) | Пошукові запити (імена, місця, роки); перегляд сторінок каталогу і сканів | Пошук записів і читання сканів |
| Дерево FamilySearch (Family Tree) | Люди, зв'язки і посилання на джерела | Лише після вашої явної згоди на кожну зміну |
| Сайти архівів (обласний архів за місцем пошуку, напр. ДАЧО, ДАКО; ЦДІАК, ЦДІАЛ), Вікіджерела, Wikimedia Commons | Пошукові запити і перегляд сторінок | Складання карти джерел |
| Duck Inspector (inspector.duckarchive.com) | Шифри справ (архів, фонд, опис, справа) — без імен людей | Перевірка, які справи є онлайн |
| Бібліотечні каталоги й генеалогічні форуми (resource.history.org.ua, genoua.name, forum.vgd.ru) | Пошукові запити і перегляд сторінок | Пошук друкованих видань і вичиток |

Запити до архівів агент лише готує; надсилаєте їх ви самі.
